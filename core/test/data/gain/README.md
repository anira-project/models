`simple_gain_network_mono.onnx` is the mono SimpleGainNetwork from
[anira-project/example-models](https://github.com/anira-project/example-models)
(Apache-2.0): `audio_out = audio_in * gain`, plus a peak value `gain_out`. The model and contract
descriptions follow anira's `extras/models/model-pool/gain.*.json`, ONNX Runtime only.
